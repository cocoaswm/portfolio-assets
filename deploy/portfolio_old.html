Condo Management App

LIVE IN PROD

A multi-condo management platform (Android app, web app, and API) that connects residents, office staff, technicians, the warehouse, and the building owner in one place. It is sold per condo, and each building only gets the features in its plan.

Architecture & Role
Development approach: I used AI coding tools to generate most of the code. I defined the requirements and permission rules, tested every change on a real Android phone, and approved every production deployment, while learning to trace each screen through the API to the database.
Tech Stack
Flutter 3 (Dart) Android APK Web PWA NestJS 11 TypeScript PostgreSQL 16 Prisma ORM Argon2 + JWT Docker Compose Cloudflare Tunnel Cloudflare Workers
What it does
  • 6-role access model: Owner, Manager, Office Admin, Warehouse, Technician, and Resident \u2014 every API request is checked for role and condo on the server.
  • Per-condo plans & feature switches: The owner picks a plan or turns individual features on or off per building; switched-off features are blocked by the API while their data is kept.
  • Repair requests end to end: Residents report with photos, the office assigns a technician, and everyone follows the job through in-ticket chat and status updates.
  • Technician attendance: Selfie check-in with a liveness check (blink, turn, smile) and GPS location; selfies are deleted automatically after 30 days.
  • Resident services: Parcels, visitor QR passes, facility booking, car and motorcycle registration, bills, complaints, and announcements.
  • Reports & languages: Thai PDF reports for each department, with a Thai, English, and Chinese interface; PIN and fingerprint unlock on Android.
  • Operations: Runs in production on Linux with Docker, with daily automatic database and photo backups and no open server ports \u2014 traffic reaches the API only through Cloudflare Tunnel.
  • Try-it demo: A public demo owner account works on a sandbox copy, so visitors can try every feature without changing live data.
